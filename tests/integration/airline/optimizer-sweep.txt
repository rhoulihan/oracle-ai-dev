Measured cost per design (live, reservation aggregate):
  design              read µs  write µs  read logical-reads  write redo-bytes
  relational               11         4                  14                 7
  monolithic document        5        53                   3              3204
  container document        5        53                   3              2509
  (container = the aggregate split into meaningful sub-docs; the ~2500-byte
   JSON write floor limits write relief — decomposition mainly helps read scope.)

Flip: document shapes win when reads outnumber writes by ~8:1 (>~89% reads);
below that the relational overlay wins on write efficiency. The recommendation
VARIES with the mix — the measured knob, not a fixed rule. Duality would give
document-shaped reads over relational storage: the write-cheap read-convenient
option for balanced workloads.
